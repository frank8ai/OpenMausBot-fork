# 6 大人类认知负荷门禁评审细则 (CL-01 ~ CL-06)

## 1. CL-01 操作步数 (Steps <= 3)
- **测量标准**：从用户发起意图的第一击开始，到核心交付物生成或闭环完成的总点击与跳转次数。
- **合格范式**：点击“生成” -> 系统根据合理默认直接产出 -> 展示结果并提供“撤销”或“微调”。（总计 1~2 步）
- **违规反模式**：点击新增 -> 弹出步骤一 -> 点击下一步 -> 选择分类 -> 点击下一步 -> 确认配置 -> 点击提交。（7 步操作，严重违规打回）

---

## 2. CL-02 行业黑话外露 (Jargon = 0)
- **测量标准**：界面所有文案、提示与状态标签的语言纯净度。
- **合格范式**：“实时同步就绪”、“检查发现 2 处安全隐患并已自动修复”。
- **违规反模式**：“AST 污点解析成功”、“RBAC 鉴权失败”、“Webhook 200 OK”。

---

## 3. CL-03 常规确认弹窗 (Modals = 0)
- **测量标准**：日常编辑、保存、提交与非不可逆操作时的阻断性弹窗数量。
- **合格范式**：操作后立即执行（乐观更新），并在界面底部轻量提示“已更新 [撤销 (Ctrl+Z)]”。
- **违规反模式**：点击保存后弹出居中遮罩 Modal：“确认保存当前修改吗？[确认] [取消]”。

---

## 4. CL-04 初次激活配置项 (Config = 0)
- **测量标准**：新用户从安装/访问到第一次体验到核心价值所需填写的表单字段数。
- **合格范式**：开箱即用，通过环境探测与上下文自动获取配置，直接呈现主功能。
- **违规反模式**：新用户初次打开必须先填写“服务器 IP、端口、API Key、通信协议、备份路径”等 8 项参数方可进入。

---

## 5. CL-05 焦点分支 (Focus <= 1)
- **测量标准**：当前视图中主要行动点 (Primary Call-to-Action) 的数量与视觉竞争度。
- **合格范式**：单一清晰的视觉视觉重心按钮（如 Linear 的单主行动键），次要操作收敛至键盘快捷键或次级菜单。
- **违规反模式**：一屏同时出现 3 个不同颜色的大按钮：“立即购买”、“预约演示”、“下载白皮书”，互相抢夺注意力。

---

## 6. CL-06 价值触达时长 (Time-to-Value <= 3s)
- **测量标准**：用户触发操作至核心价值（如研报、分析图表、任务结果）呈现在屏幕上的物理时间。
- **合格范式**：毫秒级首屏骨架呈现，3 秒内完成关键信息流首屏交付。
- **违规反模式**：全屏白屏加载转圈超过 5 秒，且无进度或阶段提示。
