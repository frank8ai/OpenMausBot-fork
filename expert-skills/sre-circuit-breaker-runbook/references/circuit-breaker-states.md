# 熔断器状态机 (Circuit Breaker) 与弹性降级架构

## 1. 经典三态有限状态机 (Finite State Machine)

```
        +-----------------------------------------+
        |                                         |
        |  [请求成功, 错误率归零]                   |
        v                                         |
  +-----------+     [错误率超阈值 / 5xx持续]     +----------+
  |  CLOSED   | -----------------------------> |   OPEN   |
  +-----------+                                +----------+
        ^                                            |
        |                                            | [冷却计时器超时]
        |                                            v
        |           [探针请求探测]              +-----------+
        +------------------------------------- | HALF-OPEN |
             [任一探针请求失败则立即返回 OPEN]    +-----------+
```

### 状态转移详解：
1. **CLOSED (闭合态 - 正常服务)**:
   - 流量 100% 穿透到达目标微服务。
   - 统计滑动时间窗口（如最近 100 次调用）内的失败率与慢调用率。
   - 触发条件：当失败率超过阈值（如 > 50%）或 5xx 占比超过基线 1%，瞬间切至 **OPEN** 态。
2. **OPEN (断开态 - 快速失败)**:
   - 熔断器开启，所有后续请求不再调用下游故障服务，直接短路（Short-Circuit）。
   - 执行预设 **Fallback 降级逻辑**（如返回本地缓存、默认静态数据或友好错误码），保护下游免受雪崩冲击。
   - 启动不可中断的冷却重试计时器（如 `sleepWindowInMilliseconds = 30000ms`）。
3. **HALF-OPEN (半开态 - 试探恢复)**:
   - 冷却时间结束后自动进入半开状态。
   - 仅放行极少量探针请求（如 5~10 个金丝雀请求）试探下游健康度。
   - **判定准则**：
     - 若所有探针请求全部成功且响应时间符合 SLO，熔断器重置为 **CLOSED**，恢复正常流量；
     - 若探针请求中发生任何一次失败或超时，立即重新切回 **OPEN**，重置冷却时间并加倍退避。

## 2. 自适应限流与拥塞控制 (Adaptive Concurrency Limits)

Netflix 与 Envoy 生产实践证明：静态并发上限往往难以适应动态波动的流量环境，自适应限流（基于 Little's Law 与 Vegas 拥塞控制算法）是现代 SRE 的标准配置：

- **核心公式**：`Limit = Limit + (QueueSize < Target ? 1 : -1)`
- **测量指标**：动态跟踪最小往返时间（minRTT）与排队延迟（Queue Delay）。当排队延迟超过容忍阈值时，自适应收缩允许并发数，在入口处直接将多余流量引入降级队列，防止下游容器 OOM 崩溃。
