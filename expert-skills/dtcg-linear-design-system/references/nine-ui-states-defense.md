# 9 大 UI 状态全防御矩阵工程落地指南

## 1. 状态矩阵防漏检查清单 (State Defense Matrix)

| 状态类型 | 核心体验目标 | 必须杜绝的反模式 | 验收标准 (Done-When) |
|---|---|---|---|
| **1. Initial** | 极速首屏占位，无白屏惊悚感 | 长时间整页空白 | 100ms 内出现页面布局框架与基础导航 |
| **2. Loading** | 1:1 骨架还原真实内容版式 | 粗暴全屏转圈 Loading Spinner | 骨架屏高度与实际卡片 100% 一致，无 CLS 布局抖动 |
| **3. Empty** | 消除迷茫感，指引唯一明确行动 | 仅留一行干瘪的“暂无数据” | 包含插画/图标 + 人话说明 + 单一主 CTA 操作按钮 |
| **4. Partial** | 渐进式渲染，优先呈现关键结论 | 必须等待所有接口全部返回才显示 | 关键核心指标先出，图表流式渐入 |
| **5. Success** | 信息层级明确，信噪比极高 | 信息密集拥挤，无主次之分 | 焦点行动明确，辅助数据低对比度弱化 |
| **6. Error** | 明确人话报错，赋予用户自愈手段 | 外露 500 Internal Error 堆栈代码 | 解释“出了什么问题”+ 醒目“立即重试”按钮 |
| **7. Disabled** | 明确不可用状态并告知原因 | 灰掉按钮但不告诉用户为什么不能点 | 附带 Tooltip 明确说明解锁条件（如需填写XX） |
| **8. Hover/Focus** | 键盘可达性保障，鼠标悬停即时反馈 | 缺乏聚焦指示环，Tab 键导航迷失 | 键盘聚焦呈现高对比度 Focus Ring，且绝不被遮挡 |
| **9. Optimistic** | 16ms 内瞬时操作闭环 | 点击后挂起等待网络往返转圈 | 操作瞬间完成界面反转，并在网络异常时自动回滚 |
